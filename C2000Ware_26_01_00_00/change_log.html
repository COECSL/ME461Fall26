Note 1: "device_cal" function address is different for different revisions of the F28P55x device. If the revision ID (value at address 0x5D00C) is "1" then define the REV_ID as a predefined symbol in the projectspec (Add "--define=REV_ID=1" in the compiler flags, which correspond to REV0). For REVID as REVA, the value will be 2, which is the default value in the package.

Note 2: I2C config name change in SysConfig : "OwnTargetAddress" has been renamed to "OwnAddress". Any .syscfg file which uses the older name has to be updated to use this new name (i2cx.ownTargetAddress to i2cx.OwnAddress)

Note 3: The TINIE naming is to be updated to NPU in driverlib functionalities/macros for F28P55x device for previous SDKs.
